Privacy Policy | SOL Rent & 11-Layer Rug Shield

Effective Date: November 15, 2026 | Domain: https://rentandrugshield.com

1. 100% Read-Only Public Blockchain Lookups

SOL Rent & Rug Shield (Web App, Standalone PWA, and Chrome Extension) is a non-custodial, read-only Solana blockchain security utility. Users can audit any public Solana token mint address across 10 pre-buy security layers or scan any public Solana wallet address for empty SPL/Token-2022 accounts using standard Solana JSON-RPC read calls (getTokenAccountsByOwner, getAccountInfo) without connecting a wallet or providing personal data.

2. Zero Custody & Zero Private Key Access

We never ask for, collect, transmit, or store private keys, seed phrases, wallet passwords, or secret recovery material. Any optional on-chain transaction (such as closing 0-balance empty SPL token accounts via the standard Solana Token Program CloseAccount 0x09 instruction) is constructed transparently and signed exclusively inside the user's own wallet software (e.g., Phantom or Solflare).

3. Chrome Extension (Manifest V3) Permissions & Data Handling

Our official Chrome Extension requests only minimal Manifest V3 permissions:

  • activeTab: Used solely when you explicitly click the toolbar extension icon to check whether the active DEX/explorer tab URL contains a public 32 to 44 character Solana token mint address for an instant 11-Layer pre-buy safety check. Browsing history is never tracked or recorded in the background.
  • storage: Used locally in your browser to remember your last audited token mint or UI preference.
  • host_permissions (rentandrugshield.com, rentshield.duckdns.org): Used strictly over HTTPS to query our 11-Layer Solana token security API and read-only wallet rent scanner API.

4. Minimal Telemetry & Zero Sale of User Data

We do not sell, rent, or transfer user data to third parties, do not use data for creditworthiness or lending, and do not run third-party advertising trackers. Aggregate service health counters are used solely to maintain API reliability and prevent automated abuse.

For privacy or security inquiries, contact ceo@rentandrugshield.com.
